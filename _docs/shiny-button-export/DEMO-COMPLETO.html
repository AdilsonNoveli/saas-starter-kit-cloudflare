✅ Como Usar:

  • Copie o CSS entre os comentários SHINY BUTTON CSS
  • Defina --background no :root
  • SEMPRE envolva o conteúdo com <span>
  • Use a classe .shiny-button
  • Funciona em Chrome 85+, Safari 15.4+, Firefox 115+

⚠️ Erro Comum:

  • ERRADO: <button class="shiny-button">Texto</button>
  • CORRETO: <button class="shiny-button"><span>Texto</span></button>
