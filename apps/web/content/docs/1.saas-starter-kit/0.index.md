**SaaS Starter Kit** is a production-ready, enterprise-grade Nuxt starter kit built for Cloudflare — deploy straight to production, no scaffolding to fill in first.

---

## Key Features

### 1. Emails

- **Templates**: [React Email](https://react.email/), component-based.
- **Provider-agnostic worker**: Resend, Amazon SES, Mailgun, Sparkpost, or custom SMTP.

### 2. Authentication (Nuxfire Auth)

An independent authentication server (OpenAuth.js), deployable to secure any frontend or backend, at `auth.YOUR-DOMAIN.com`:

- Google and GitHub social login.
- Code-based login and email/password login, with password recovery.
- Extendable with new authentication methods.

### 3. Infrastructure

Infrastructure as code — deploy and tear down as many environments as you need, on any Cloudflare account.

### 4. Content Site

Hosted on `YOUR-DOMAIN.com`: landing page, blog, docs, and site-wide search, all built in.

### 5. Application Dashboard

Deployed to `app.YOUR-DOMAIN.com`:

- Async jobs via Cloudflare Queues and cron triggers.
- Stripe and Paddle billing.
- Real-time notifications over WebSockets.
- Teams — members, invites, role-based access control.

### 6. WebSockets Server

Real-time communication over Cloudflare Durable Objects, at `websockets.YOUR-DOMAIN.com`.

### 7. Additional

- Blob storage (R2) via `@nuxt-hub/core` — the database itself is Postgres via Hyperdrive, not a NuxtHub-managed store (see [Database](/docs/saas-starter-kit/features/database)).
- Internationalization (i18n).
- SEO built in.
