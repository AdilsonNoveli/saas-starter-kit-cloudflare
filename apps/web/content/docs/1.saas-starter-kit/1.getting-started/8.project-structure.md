Nuxfire is a Bun workspace monorepo (`apps/*`, `packages/*`, `layers/*`), all under the `@nuxfire/*` namespace. `apps/` holds deployable applications; `packages/` holds shared libraries with no deploy of their own; `layers/` holds pluggable business-domain Nuxt Layers, each one extended into `apps/app` and configured in root `config.ts`.

## Monorepo Breakdown

### Applications (`apps/`)

- **`apps/app`** — the Composition Root: the app shell (dashboard layout, navigation, tRPC composition), extending every active layer. Business logic itself lives in `layers/`, not here.
- **`apps/web`** — the public site: landing page, blog, and this documentation, built with Nuxt Content.
- **`apps/login`** — the login/signup/forgot-password UI, built statically and served as the auth Worker's static assets.
- **`apps/functions`** — Cloudflare Workers code: the OpenAuth auth issuer, the email Worker, the WebSockets Worker, the job/dead-letter queue consumers, and the hourly Cron Worker. Also home to `src/database/` — the base Drizzle schema and migrations.

### Domain Layers (`layers/`)

Business domains live in `layers/` as modular Nuxt Layers. Each layer with persistent state owns its independent `drizzle.config.ts`, `migrations/` directory, and `layer.manifest.ts`:

- **Core Layers (`layers.core`)**: Always compiled and active for every tenant:
  - **`layers/account`** (`@nuxfire/layer-account`) — user profile, avatar upload, appearance preferences, active sessions, account deletion, user MFA (TOTP) enrollment/challenge/recovery codes, and the onboarding flow (`/onboarding`).
  - **`layers/teams`** (`@nuxfire/layer-teams`) — multi-tenancy, team workspaces, memberships, invitations, roles and RBAC permissions (`nuxt-authorization`), team switcher, and async jobs/DLQ models (`Job`, `DeadLetterRecord`).
  - **`layers/notifications`** (`@nuxfire/layer-notifications`) — real-time in-app notifications over WebSockets, notification slideover, and read status tracking.
  - **`layers/admin`** (`@nuxfire/layer-admin`) — platform administration console (`/admin`), platform admin MFA enforcement, audit logs, DLQ management, and company oversight.
- **Feature Layers (`layers.features`)**: Independently toggleable in `config.ts`:
  - **`layers/billing`** (`@nuxfire/layer-billing`) — Stripe and Paddle subscriptions, checkouts, billing portal, webhooks, plans and benefits, and team settings billing tab.
  - **`layers/kanban`** (`@nuxfire/layer-kanban`) — optional kanban boards, columns, cards/tasks, drag-and-drop, and team navigation sidebar entry.

### Shared Packages (`packages/`)

- **`packages/crypto`** (`@nuxfire/crypto`) — pure Web Crypto security primitives: AES-GCM encryption/decryption, HMAC-SHA256, constant-time `secretsMatch`, MFA recovery codes, and signed WebSocket tickets. Zero runtime dependencies.
- **`packages/rate-limit`** (`@nuxfire/rate-limit`) — pure fixed-window rate limiting algorithm (`core.ts`) and adapters (`adapters.ts`) for Cloudflare KV (`kvNamespaceStore`) and NuxtHub KV (`hubKvStore`).
- **`packages/emails`** (`@nuxfire/emails`) — `packages/emails/templates` (email templates built with React Email) plus `packages/emails/mailer` (provider-agnostic send engine for Resend, SES, Mailgun, SparkPost, SMTP) — see [Emails](/docs/saas-starter-kit/features/emails).
- **`packages/tokens`** (`@nuxfire/tokens`) — `@nuxfire/tokens`, the single source of truth for theming (brand colors, corner radius, dark-mode surface mapping, Nuxt UI component overrides), consumed by every app and layer alike — see [Design System & Branding](/docs/saas-starter-kit/concepts/design-system).
- **`packages/manifest`** (`@nuxfire/manifest`) — `@nuxfire/manifest`, the shared `defineLayerManifest()` contract every layer's `layer.manifest.ts` uses.

Everything outside `apps/`, `packages/` and `layers/` that isn't application code is infrastructure: `infra/*.ts` defines every Cloudflare resource as SST — see [SST.dev](/docs/saas-starter-kit/concepts/sst).

## Architecture Tree

```text
nuxfire/
├── apps/
│   ├── app/           # Composition Root: UI shell & tRPC composition
│   ├── functions/     # Cloudflare Workers: Auth issuer, Mailer, WebSockets, Cron, Queues
│   ├── login/         # Static Nuxt auth UI: Login, Signup, Forgot Password
│   └── web/           # Public site: Landing page, Blog, Docs (Nuxt Content)
├── layers/
│   ├── account/       # Core: Profile, preferences, sessions, user MFA, onboarding
│   ├── admin/         # Core: Platform admin console, admin MFA, audit logs, DLQ
│   ├── billing/       # Feature: Stripe & Paddle billing, checkouts, plans
│   ├── kanban/        # Feature: Boards, lists, task cards, drag-and-drop
│   ├── notifications/ # Core: In-app notifications, WebSocket delivery, slideover
│   └── teams/         # Core: Multi-tenancy, memberships, invitations, RBAC
├── packages/
│   ├── crypto/        # Pure Web Crypto: AES-GCM, HMAC, constant-time compare, tickets
│   ├── emails/        # React Email templates & provider-agnostic mailer engine
│   ├── manifest/      # Layer manifest contracts & defineLayerManifest schema
│   ├── rate-limit/    # Fixed-window rate limiting core & KV adapters
│   └── tokens/        # Design tokens, color themes, CSS variables & theme.css
└── infra/             # SST infrastructure definitions (Cloudflare resources)
```
