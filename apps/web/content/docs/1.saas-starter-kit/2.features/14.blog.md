NuxFire comes with a minimal blog system built with [Nuxt Content](https://content.nuxt.com/). Add markdown files to start publishing.

## What's Included

- Minimal blog index and post pages
- Site-wide search integration
- SEO optimization
- Responsive design
- Dark mode support

## File Structure

Blog posts live in `apps/web/content/blog`, as its own Nuxt Content collection (`apps/web/content.config.ts`) with a required `date` and `author` on every post's frontmatter:

```yaml
---
title: "Post title"
date: "2026-01-15"
author: "Your Name"
---
```
