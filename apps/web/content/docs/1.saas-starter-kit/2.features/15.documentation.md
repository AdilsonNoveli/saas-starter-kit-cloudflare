NuxFire's documentation site (what you're reading now) is built on [Nuxt Content](https://content.nuxt.com/).

As you add features, add new markdown files under `apps/web/content/docs` and they're automatically included in navigation and search — the numeric prefix on each file/folder (`1.getting-started`, `2.features`, ...) controls ordering and is stripped from the generated URL.

## What's Included

- Nuxt Content, configured as a `docs` collection (`apps/web/content.config.ts`) alongside separate `blog`, `faqs`, and `legal` collections.
- Prose-component theming, so rendered markdown matches the rest of the site.
- Full-text search.
- Mobile-optimized navigation.
- Dark mode support.

## Prose Components

Markdown elements are themed through Nuxt Content's own override mechanism — a component named `Prose<Tag>` under `apps/web/app/components/content/` replaces the default rendering for that tag, applied automatically with no per-page markup:

```
apps/web/app/components/content/
  ProseA.vue        ProseH1.vue ... ProseH6.vue    ProseTable.vue
  ProseCode.vue      ProseBlockquote.vue            ProseUl.vue / ProseOl.vue / ProseLi.vue
  ProseCodeInline.vue  CodeCopy.vue   Center.vue     ...
```

## Search

Full-text search is included out of the box, powered by Nuxt Content.

## Customization

```typescript [apps/web/nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    build: {
      markdown: {
        highlight: {
          langs: ["ts", "vue", "bash"],
          theme: {
            default: "github-light",
            dark: "github-dark",
            sepia: "monokai",
          },
        },
      },
    },
  },
});
```
