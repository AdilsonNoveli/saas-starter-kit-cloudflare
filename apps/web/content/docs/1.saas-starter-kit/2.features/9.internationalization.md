> English and French are pre-configured — add your own languages and translations.

## What's Included

- Pre-configured locale management
- A language switcher, built into the account dropdown menu

## Configuration

Locales are set up in `nuxt.config.ts`:

```typescript [apps/app/nuxt.config.ts]
i18n: {
  vueI18n: "./i18n.config.ts",
  defaultLocale: "en",
  strategy: "no_prefix",
  locales: [
    { name: "English (US)", code: "en", language: "en-US" },
    { name: "French", code: "fr", language: "fr" },
  ],
}
```

## Translation Messages

Translations live in `apps/app/i18n.config.ts`:

```typescript [apps/app/i18n.config.ts]
export default defineI18nConfig(() => ({
  legacy: false,
  locale: "en",
  messages: {
    en: { welcome: "Welcome to the dashboard!" },
    fr: { welcome: "Bienvenue sur le tableau de bord !" },
  },
}));
```

## Language Switcher

The switcher isn't a standalone component — it's a `children` array inside the account dropdown menu (`apps/app/app/components/account/AccountUserDropdown.vue`), built from `useI18n()`'s own locale list:

```typescript
const { locale, locales, setLocale } = useI18n();

const localeChildren = computed(() =>
  locales.value.map((item) => ({
    label: item.name ?? item.code,
    type: "checkbox",
    checked: locale.value === item.code,
    onSelect: (event: Event) => {
      event.preventDefault();
      setLocale(item.code);
    },
  })),
);
```
