**Skill:** `fireskill-setup` · **Asks questions:** yes · **Changes:** `.fireskills/USER-PROFILE.md`, `.fireskills/*`, the managed block of `AGENTS.md` and `CLAUDE.md`

## When to use it

- The first time you open the repository with an agent.
- When the [context monitor](/docs/fireskills/getting-started/project-context) says something is out of date and you want the context reconciled.

You do not need to type it before each step: every flow skill loads the setup by itself before it starts.

## What to type

```text
Use $fireskill-setup para detectar o stack, consultar respostas confirmadas, adaptar as perguntas ao nível de conhecimento e monitorar pendências documentais.
```

## What the agent does

1. Reads, in this order: `.fireskills/USER-PROFILE.md`, the conversation, the context files (`PROJECT`, `DESIGNSYSTEM`, `STACK`, `RULES`, `DATABASE`, `PACKAGES`), `AGENTS.md`/`CLAUDE.md`, and the specs that exist.
2. If your knowledge level is not recorded (`Nível atual | A confirmar` in `USER-PROFILE.md`), it asks the first question:

   ```text
   Pergunta 1. Como você prefere receber as orientações deste setup?
   1. Iniciante: explique os termos técnicos e o efeito de cada escolha antes de prosseguir.
   2. Intermediário: conheço os fundamentos e prefiro explicações curtas junto das escolhas.
   3. Experiente: posso responder com detalhes de stack, arquitetura, comandos e integrações.
   4. Escrever outra resposta
   5. Gere outras opções
   6. Avançar
   ```

   Your answer is saved as `iniciante`, `intermediário` or `experiente`, with its source and date. It changes the wording of later questions, not what the agent assumes.
3. Goes through the subjects that are still unanswered, one question per round: product goal, users and roles, access and permissions, main data, screens and navigation, tests/observability/deploy, external integrations. A subject the files already answer is not asked again.
4. Reconciles the context files and the reserved blocks of `AGENTS.md` and `CLAUDE.md`, detects the stack, and runs the monitor.

Nuxfire already ships filled context (`PROJECT`, `STACK`, `RULES`, `DATABASE`, `INTERFACE`, `DESIGNSYSTEM`), so on a downloaded copy the setup usually asks only about the knowledge level and real gaps.

## Database protection

Tests that touch PostgreSQL need a test database different from the one in the stage secrets. Until that separation is proven, the flow runs no such test. The 131 Vitest tests that exist today replace `useDB`, so they do not touch a database.

## Result

- `.fireskills/USER-PROFILE.md` with your answers.
- Context files reconciled; monitor output `Context monitor: CURRENT`.
