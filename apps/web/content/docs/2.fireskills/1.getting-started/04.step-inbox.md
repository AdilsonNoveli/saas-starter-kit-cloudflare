**Skill:** `fireskill-01-inbox` · **Asks questions:** no · **Creates:** `specs/inbox/<AAAA-MM-DD-HHMMSS>-<slug>.md`

## When to use it

You have a raw idea, a request from someone, or a bug report, and you want it saved right now without being interrogated.

## What to type

```text
Use $fireskill-01-inbox para registrar este texto imediatamente, sem perguntas, em specs/inbox/.

Donos de equipe devem convidar membros por e-mail; o link expira em 48 horas.
```

The first line is the shipped prompt. Write your text below it.

## What the agent does

1. Silently checks for credentials, tokens, private keys and obvious personal data. If it finds any, **it does not save the file**: it tells you to remove the sensitive data and send the idea again.
2. Runs `fireskills/skills/fireskill-01-inbox/scripts/capturar_inbox.mjs` with a `--title` and your text as `--input`.
3. Preserves your wording as-is and stores a SHA-256 of the original.
4. Adds an initial analysis (problem, people affected, expected result, risks) separated into statement, **inference** and **to review**, never as a decision. Where the text gives no basis it writes `Não identificado no texto original.`
5. Asks nothing, does not block on duplicates or missing context, and reports only the file path and a short summary.

You do not write this file by hand: the template has a fixed structure that later skills read.

## Result

`specs/inbox/2026-09-18-174245-convite-de-membros-por-e-mail.md`, starting with:

```markdown
# Inbox: Convite de membros por e-mail

| Metadado | Valor |
| --- | --- |
| Status | Capturada |
| Capturada em | 2026-09-18T20:42:45Z |
| Slug | convite-de-membros-por-e-mail |
| Origem | Input do usuário |
| Processamento | Análise inicial sem perguntas |
| Integridade do original | SHA-256 `556c4ccafe2e…` |
| Backlog derivado | Nenhum |
| Spec derivada | Nenhuma |

## Texto original
```

An inbox file is never changed or deleted by later steps; backlog and spec only point back to it.

## Next

The inbox skill does **not** start the next step by itself. To refine the idea, type the [Step 2: Backlog](/docs/fireskills/getting-started/step-backlog) prompt. You may also stop here and keep the idea in `specs/inbox/` for later.
