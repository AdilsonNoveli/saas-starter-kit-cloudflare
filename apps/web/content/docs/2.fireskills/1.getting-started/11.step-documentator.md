**Skill:** `fireskill-documentator` · **Asks questions:** no · **Changes:** `docs/` at the repository root and `.fireskills/PACKAGES.md`

## When to use it

- After every `[CODE]` task: `$fireskill-07-implement` calls it for you.
- Whenever the [monitor](/docs/fireskills/getting-started/project-context) says `docs/` or `PACKAGES.md` must be rebuilt.
- On demand, with no spec at all.

## What to type

```text
Use $fireskill-documentator para reconstruir a documentação técnica em docs/ e o inventário .fireskills/PACKAGES.md.
```

## What the agent does

1. Reads the local instructions, `.fireskills/*`, manifests, lockfiles, installed metadata and the existing code.
2. Rebuilds the documentation:

   ```bash
   node fireskills/skills/fireskill-documentator/scripts/build_documentation.mjs --project .
   ```

3. Inspects the generated files and fixes by hand only what the code does not support.
4. Proves the result matches the current state:

   ```bash
   node fireskills/skills/fireskill-documentator/scripts/build_documentation.mjs --project . --check
   ```

5. Records the command, result and updated files in the task evidence.

It asks nothing: what the sources do not support is written as not identified.

## What it writes

| Where | Content |
|---|---|
| `docs/` (repository root) | portal and reading order, architecture, application inventory, database and entities, flows, tests, frontend (pages, Vue components, `@nuxt/ui`), packages and libraries, integrations and configuration variables (no secret values), decisions |
| `.fireskills/PACKAGES.md` | every npm/Bun package from the manifests and lockfiles, with manager, scope, name, version and source |

Text you wrote outside the blocks marked `specsfy:documentator` is kept.

## What it does **not** write

The public documentation of this site (`apps/web/content/docs/`) is not touched by this skill. Those pages are edited by hand.

`docs/` is an **inventory built by heuristics** from the code. It is useful to see what exists, but it is not architecture prose, and the skill itself forbids presenting a heuristic as a confirmed decision. For the tables of the database, `.fireskills/DATABASE.md` is the reference.
