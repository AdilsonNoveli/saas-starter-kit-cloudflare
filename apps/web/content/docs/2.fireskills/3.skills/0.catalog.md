Fireskills provides 23 specialized skills that guide AI agents and engineering teams through every phase of the software engineering lifecycle.

---

## Complete Skills Matrix

### Core Lifecycle Skills

| Skill | Phase / Act | Primary Purpose |
|---|---|---|
| [`fireskill-01-inbox`](/docs/fireskills/skills/act-1-define) | Act I: Define | Captures raw ideas and feature requests into `specs/inbox/` without interruption. |
| [`fireskill-02-backlog`](/docs/fireskills/skills/act-1-define) | Act I: Define | Creates a backlog item from an idea and refines it by numbered questions. |
| [`fireskill-03-specify`](/docs/fireskills/skills/act-1-define) | Act I: Define | Authors the initial canonical `spec.md` with requirements and Gherkin BDD scenarios. |
| [`fireskill-04-validate`](/docs/fireskills/skills/act-1-define) | Act I: Define | Validates definition completeness, AC coverage, and seals the Definition Gate. |
| [`fireskill-05-tasks`](/docs/fireskills/skills/act-2-design-prove) | Act II: Design & Prove | Decomposes specifications into atomic tasks with mandatory 6-step checklists. |
| [`fireskill-06-tdd-bdd`](/docs/fireskills/skills/act-2-design-prove) | Act II: Design & Prove | Derives Vitest cases from the BDD scenarios and observes a valid RED. |
| [`fireskill-07-implement`](/docs/fireskills/skills/act-3-deliver) | Act III: Deliver | Implements production code in RED → GREEN → REFACTOR discipline, seals Delivery Gate. |
| [`fireskill-documentator`](/docs/fireskills/skills/act-3-deliver) | Act III: Deliver | Rebuilds `docs/` and `.fireskills/PACKAGES.md` from the code. |
| [`fireskill-progress`](/docs/fireskills/skills/act-3-deliver) | Act III: Deliver | Visualizes current progress across all specifications, states, and milestones. |

### Governance & Discovery Skills

| Skill | Category | Primary Purpose |
|---|---|---|
| [`fireskill-setup`](/docs/fireskills/skills/governance-and-decisions) | Governance | Reconciles the `.fireskills/` context, asks your knowledge level and the unanswered subjects, and runs the monitor. |
| [`fireskill-update-spec`](/docs/fireskills/skills/governance-and-decisions) | Lifecycle Update | Handles changes to a spec that already passed the Definition Gate, reopening only the necessary acts and gates. |
| [`fireskill-interviewer`](/docs/fireskills/skills/governance-and-decisions) | Discovery | Enables conversational exploration of specifications across any active state. |
| [`fireskill-data-discovery`](/docs/fireskills/skills/governance-and-decisions) | Data & Schema | Probes product storage requirements using everyday language and syncs `DATABASE.md`. |
| [`fireskill-lessons`](/docs/fireskills/skills/governance-and-decisions) | Memory & Learning | Records preventive rules from real failures in `.fireskills/lessons.json` and `LESSONS.md`. |
| [`fireskill-the-jury`](/docs/fireskills/skills/governance-and-decisions) | Decision Making | Collegiate deliberation by a panel of 3 to 5 subagents for high-impact decisions. |
| [`fireskill-the-fool`](/docs/fireskills/skills/governance-and-decisions) | Adversarial Review | Stress-tests specifications to expose fragile assumptions, edge cases, and failure modes. |
| [`fireskill-the-judge`](/docs/fireskills/skills/governance-and-decisions) | Code Review | Evidence-based code review analyzing PRs and diffs against repository contracts. |
