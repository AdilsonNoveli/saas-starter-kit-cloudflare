AI models frequently fail in complex codebases because they make assumptions based on general internet training data rather than the specific patterns, libraries, and runtime constraints of the target repository.

Fireskills solves this through **34 Technical Specialists** located in `fireskills/specialists/`. Each specialist provides deep, focused domain expertise, code examples, and explicit boundary lists.

---

## The Golden Rule: Load Before Coding

Agents must load the relevant specialist **before** reading or writing code in that domain:

```markdown
  - [ ] **PREP**: Carregar fireskill-specialist-application-security e fireskill-specialist-trpc
  - [ ] **EXECUTE**: Implementar a verificação do webhook no caminho declarado na tarefa
```

Specialists guide architectural patterns and quality verification; they do not author specifications or alter quality gates autonomously.

---

## The "What Exists" vs. "What DOES NOT Exist" Contract

The ten Nuxfire stack specialists include a `references/nuxfire-*.md` file, written from the real code, with two sections that matter most:

### 1. What Actually Exists in the Codebase
- Exact package versions and imports.
- Reusable utilities, composables, and service functions.
- Canonical patterns verified in production.

### 2. What DOES NOT Exist in the Codebase
- Libraries and frameworks the project does not use (each list is specific to its specialist).
- Patterns the runtime does not allow (for example, a database client cached across requests in a Worker).
- Legacy APIs of earlier major versions.

> **Crucial Rule**: Agents must never introduce or assume packages or patterns listed in the "What DOES NOT Exist" section.

## Specialist Categories

The 34 specialists are divided into two main categories:

1. [**The 11 Nuxfire Stack Specialists**](/docs/fireskills/specialists/nuxfire-stack): Tailored specifically to the Nuxt 4, Cloudflare Workers, SST 4, tRPC, and Drizzle stack used in Nuxfire.
2. [**The 23 Engineering Specialists**](/docs/fireskills/specialists/engineering-specialists): Cross-cutting experts covering TypeScript, PostgreSQL, software architecture, security, performance, accessibility, code review, and git workflows.
