Beyond stack-specific tools, Fireskills equips AI agents with 23 domain specialists that embody enterprise software engineering practices.

---

## Languages & Data Modeling

| Specialist | Scope & Competency |
|---|---|
| `fireskill-specialist-typescript` | Advanced type system modeling, generic utilities, strict compiler configurations, and type-safe schema validation. |
| `fireskill-specialist-postgres` | PostgreSQL relational design, composite indexes, query optimization, concurrency control, and migrations over Hyperdrive. |
| `fireskill-specialist-data-modeling` | Relational entity lifecycles, normal forms, transactional integrity, and persistent schema contracts in Drizzle. |
| `fireskill-specialist-domain-modeling` | Domain-Driven Design (DDD), ubiquitous language, business aggregates, domain events, and bounded contexts across layers. |

## Architecture & API Design

| Specialist | Scope & Competency |

## Security, Performance & Quality
