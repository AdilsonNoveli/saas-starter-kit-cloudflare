Poner en marcha una etapa de Nuxfire consta de 6 pasos, cada uno en su propia página. Siga el orden indicado la primera vez; vuelva a cualquiera de ellos más adelante como referencia.

## Requisitos previos

Antes de comenzar, necesitará:

- Una cuenta de Cloudflare en un **plan de pago**: se requiere Workers Paid para websockets y colas (queues). Actívelo desde la pantalla "Get started with R2" (se requiere una tarjeta de crédito aunque R2 cuenta con un nivel gratuito generoso):

  ![Comience con R2](/images/docs/Get-started-with-R2.webp)

- Un dominio configurado con servidores de nombres (nameservers) de Cloudflare.
- Una base de datos Postgres real: Supabase, RDS, Neon, autohospedada o cualquier Postgres estándar. La conexión se realiza siempre a través del protocolo nativo de Postgres, nunca mediante un SDK específico del proveedor.
- Acceso inmediato al código fuente completo de Nuxfire descargado de su **Área de Miembros** después de la compra.

Para conocer la disposición del código base, consulte [Estructura del Proyecto](/docs/saas-starter-kit/getting-started/project-structure). Para ver cómo Postgres se conecta al entorno de ejecución de Workers, consulte [Base de Datos](/docs/saas-starter-kit/features/database).

## Los pasos

1. [Instalación](/docs/saas-starter-kit/getting-started/installation): instale Bun, clone el repositorio e instale las dependencias.
2. [Acceso a Cloudflare](/docs/saas-starter-kit/getting-started/cloudflare-access): cree el token de API que necesita cada comando `sst`.
3. [Configuración](/docs/saas-starter-kit/getting-started/configuration): defina su dominio y los flags de características en `config.ts`.
4. [Secrets](/docs/saas-starter-kit/getting-started/secrets): cargue sus credenciales en la bóveda de SST. ¿Necesita saber de dónde proviene un valor específico? Consulte [Variables de Entorno](/docs/saas-starter-kit/getting-started/environment-variables).
5. [Despliegue](/docs/saas-starter-kit/getting-started/deploy): despliegue su etapa y, posteriormente, producción.
6. [Desarrollo Local](/docs/saas-starter-kit/getting-started/local-development): ejecute la aplicación localmente en el día a día.

Una vez desplegada, la creación de la cuenta de propietario de la plataforma es un paso manual y deliberado; consulte [Consola de Platform Admin](/docs/saas-starter-kit/features/platform-admin).
