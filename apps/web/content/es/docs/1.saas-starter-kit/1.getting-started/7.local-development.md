## Local dev server

Utiliza wrangler/miniflare para emular bindings de Cloudflare:

```bash
bun run app    # run the main app locally
bun run web    # run the public site locally
```

## Remote dev

Se conecta a la infraestructura que ya ha desplegado, en lugar de emularla:

```bash
bun run app-remote
bun run web-remote
```

**Prompt para agentes de IA:**
```text
Ask which the user wants: local (bun run app / bun run web — emulates
Cloudflare bindings) or remote (bun run app-remote / bun run web-remote
— connects to the deployed stage). Run only the one they choose.
```
