Nuxfire incluye un sistema de blog minimalista construido con [Nuxt Content](https://content.nuxt.com/). Agregue archivos markdown para comenzar a publicar.

## What's Included

- Páginas mínimas de índice y artículos de blog
- Integración con búsqueda en todo el sitio
- Optimización para SEO
- Diseño responsivo
- Soporte para modo oscuro

## File Structure

Los artículos del blog residen en `apps/web/content/blog`, como una colección propia de Nuxt Content (`apps/web/content.config.ts`) con `date` y `author` obligatorios en el frontmatter de cada publicación:

```yaml
---
title: "Post title"
date: "2026-01-15"
author: "Your Name"
---
```
