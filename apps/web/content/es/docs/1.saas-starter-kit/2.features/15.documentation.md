El sitio de documentación de Nuxfire (lo que está leyendo ahora) está construido sobre [Nuxt Content](https://content.nuxt.com/).

A medida que agregue características, añada nuevos archivos markdown bajo `apps/web/content/docs` y se incluirán automáticamente en la navegación y la búsqueda: el prefijo numérico en cada archivo/carpeta (`1.getting-started`, `2.features`, ...) controla el orden y se suprime de la URL generada.

## What's Included

- Nuxt Content, configurado como una colección `docs` (`apps/web/content.config.ts`) junto con las colecciones independientes `blog`, `faqs` y `legal`.
- Tematización de componentes Prose, para que el markdown renderizado coincida con el resto del sitio.
- Búsqueda de texto completo.
- Navegación optimizada para dispositivos móviles.
- Soporte para modo oscuro.

## Prose Components

Los elementos de Markdown se tematizan mediante el mecanismo de anulación propio de Nuxt Content: un componente llamado `Prose<Tag>` bajo `apps/web/app/components/content/` reemplaza la representación predeterminada de esa etiqueta, aplicándose automáticamente sin marcado individual por página:

```
apps/web/app/components/content/
  ProseA.vue        ProseH1.vue ... ProseH6.vue    ProseTable.vue
  ProseCode.vue      ProseBlockquote.vue            ProseUl.vue / ProseOl.vue / ProseLi.vue
  ProseCodeInline.vue  CodeCopy.vue   Center.vue     ...
```

## Search

La búsqueda de texto completo se incluye de serie, impulsada por Nuxt Content.

## Customization

```typescript [apps/web/nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    build: {
      markdown: {
        highlight: {
          langs: ["ts", "vue", "bash"],
          theme: {
            default: "github-light",
            dark: "github-dark",
            sepia: "monokai",
          },
        },
      },
    },
  },
});
```
