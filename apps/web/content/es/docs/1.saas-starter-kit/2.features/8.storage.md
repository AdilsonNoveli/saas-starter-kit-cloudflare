title: "Almacenamiento"

Nuxfire utiliza Cloudflare R2 para almacenamiento de blobs (imágenes de perfil y logos de equipo en la actualidad).

Utiliza las utilidades del módulo `@nuxt-hub/core` específicamente para esto, aunque la base de datos sea Postgres mediante Hyperdrive y no un almacenamiento gestionado por NuxtHub (consulte [Base de Datos](/docs/saas-starter-kit/features/database)): el modo autohospedado de NuxtHub espera un enlace llamado exactamente `BLOB` (fijado por el propio NuxtHub), por lo que el bucket R2 se nombra de esa forma en lugar de desplegarse a través de la plataforma de NuxtHub.

## Configuration

R2 se configura en dos ubicaciones:

```typescript [apps/app/nuxt.config.ts]
export default defineNuxtConfig({
  hub: {
    blob: true, // enables R2 storage using NuxtHub's utilities
    kv: true,
    cache: true,
  },
});
```

Infraestructura como código:

```typescript [infra/utils/nuxt.ts]
// NuxtHub's self-hosted mode expects this binding named exactly BLOB —
// that's fixed by NuxtHub itself, not something `link` can rename.
link.push(
  database,
  new sst.cloudflare.Bucket("BLOB"),
  new sst.cloudflare.Kv("KV"),
  new sst.cloudflare.Kv("CACHE"),
  emails,
);
```

## Usage

```typescript
// Get the blob client
const blob = hubBlob();

// Upload a file
await blob.put("path/to/file.jpg", fileContent);

// Download a file
const file = await blob.get("path/to/file.jpg");

// Delete a file
await blob.del("path/to/file.jpg");
```

### Real-world example: profile pictures

```typescript
// Delete the old profile picture before storing the new one
const previousKey = user.image.slice(baseUrl.length);
if (previousKey.startsWith("profile/")) {
  try {
    await hubBlob().del(previousKey);
  } catch {
    // didn't exist
  }
}
```
