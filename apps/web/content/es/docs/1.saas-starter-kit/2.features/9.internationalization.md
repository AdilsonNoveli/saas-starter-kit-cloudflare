---
title: "Internacionalización"
description: "Nuxfire incluye soporte para internacionalización mediante @nuxtjs/i18n, facilitando servir su aplicación en múltiples idiomas."
---

> Inglés, Portugués de Brasil y Español vienen preconfigurados — agregue sus propios idiomas y traducciones.

## What's Included

- Gestión de locales preconfigurada en todas las apps y layers
- Un selector de idioma dedicado en la página de configuración de Apariencia y en la barra de navegación pública

## Configuration

Los locales se configuran en `nuxt.config.ts`:

```typescript [apps/app/nuxt.config.ts]
i18n: {
  restructureDir: "i18n",
  defaultLocale: "en",
  strategy: "no_prefix",
  locales: [
    { name: "English (US)", code: "en", language: "en-US", file: "en.json" },
    {
      name: "Português (Brasil)",
      code: "pt-br",
      language: "pt-BR",
      file: "pt-BR.json",
    },
    { name: "Español", code: "es", language: "es-ES", file: "es.json" },
  ],
  experimental: { typedOptionsAndMessages: "default" },
}
```

## Translation Messages

Las traducciones se estructuran en el directorio `i18n/locales/` como archivos JSON individuales (`en.json`, `pt-BR.json`, `es.json`) en cada app y layer (por ejemplo, `apps/app/i18n/locales/` y `layers/*/i18n/locales/`). La configuración en tiempo de ejecución en `i18n.config.ts` define opciones de respaldo (fallback):

```typescript [apps/app/i18n/i18n.config.ts]
export default defineI18nConfig(() => ({
  legacy: false,
  fallbackLocale: "en",
}));
```

## Language Switcher

En el panel de control, la selección de idioma se encuentra en **Configuración de Cuenta → Apariencia** (`apps/app/app/pages/account-settings/appearance.vue`), junto a las preferencias de tema:

```vue [apps/app/app/pages/account-settings/appearance.vue]
<script setup lang="ts">
const { locale, locales, setLocale } = useI18n();
</script>

<template>
  <UPageCard title="Language" description="Choose the language used across Nuxfire." variant="subtle">
    <div class="flex flex-col gap-1">
      <button
        v-for="item in locales"
        :key="item.code"
        type="button"
        class="flex items-center justify-between gap-3 px-3 py-2 rounded-md transition-colors cursor-pointer"
        :class="locale === item.code ? 'bg-primary/10 text-primary font-medium' : 'hover:bg-elevated text-default'"
        @click="setLocale(item.code)"
      >
        <span class="text-sm">{{ item.name ?? item.code }}</span>
        <UIcon v-if="locale === item.code" name="i-lucide-check" class="size-4" />
      </button>
    </div>
  </UPageCard>
</template>
```
