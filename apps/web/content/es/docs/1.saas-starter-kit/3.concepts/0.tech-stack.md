## Auth & authorization

| | Purpose |
|---|---|
| [OpenAuth.js](https://github.com/openauthjs/openauth) | Servidor de autenticación independiente (`apps/functions/src/auth.ts`): contraseña, código, GitHub, Google |
| [nuxt-authorization](https://www.npmjs.com/package/nuxt-authorization) | RBAC con alcance de equipo (habilidades estilo Bouncer) |

| `otpauth` | Generación/verificación de TOTP para MFA de platform admin y de usuario |
| `uqr` | Renderizado de códigos QR en el cliente para inscripción en MFA (cero dependencias en ejecución) |

## Infrastructure — Cloudflare, via SST

Desplegado íntegramente como código con [SST](https://sst.dev) (`sst` 4.14.0) y sus proveedores Pulumi (`cloudflare` 6.20.0, `command` 1.0.1, `random` 4.17.0); consulte [SST.dev](/docs/saas-starter-kit/concepts/sst).

| Cloudflare service | Used for |
|---|---|
| Workers | Cada aplicación desplegada (App, Auth, Web, Emails, Websockets, consumidores job/DLQ, Cron) |
| Hyperdrive | Pool de conexiones a Postgres desde Workers |
| KV | Credenciales de autenticación (`AuthKV`), contadores de rate limit, valores pequeños en caché |
| R2 (via `@nuxt-hub/core`) | Almacenamiento de blobs: imágenes de perfil, logos de equipos |
| D1 | Base de datos de contenido del sitio de documentación (buscador de `apps/web`): requerido por `@nuxt/content` en Cloudflare |
| Queues | Procesamiento de trabajos asíncronos y cola de mensajes fallidos (dead-letter) |
| Durable Objects | El servidor de WebSockets |
| Cron Triggers | Tareas programadas |
| Custom Domains | Dominio público de cada Worker, con DNS gestionado automáticamente |
