title: "NuxtHub"
description: "Por qué aparece @nuxt-hub/core en Nuxfire a pesar de que la aplicación no se despliega mediante la plataforma de NuxtHub."
---

[NuxtHub](https://hub.nuxt.com) normalmente es tanto un módulo de Nuxt (`@nuxt-hub/core`) *como* una plataforma de alojamiento: usted escribe código frente a sus utilidades `hubBlob()`/`hubKV()`/`hubDatabase()` y luego despliega a través de la CLI de NuxtHub, que aprovisiona y factura los recursos de Cloudflare correspondientes.

Nuxfire utiliza únicamente la parte del módulo. El despliegue se gestiona íntegramente mediante [SST](/docs/saas-starter-kit/concepts/sst); nada se aprovisiona ni se factura a través de la plataforma de NuxtHub.

## Why use it at all, then

Las utilidades de `@nuxt-hub/core` son lo suficientemente prácticas como para conservarlas incluso sin la ruta de despliegue de NuxtHub, y un detalle impone la integración: el modo autohospedado de NuxtHub espera que sus enlaces se llamen **exactamente** `BLOB`, `KV`, `CACHE` (nombres fijados por el propio NuxtHub, no algo que `link` de SST pueda renombrar). Por ello, `infra/utils/nuxt.ts` aprovisiona recursos reales de Cloudflare con esos nombres exactos:

```typescript [infra/utils/nuxt.ts]
link.push(
  database,
  new sst.cloudflare.Bucket("BLOB"),
  new sst.cloudflare.Kv("KV"),
  new sst.cloudflare.Kv("CACHE"),
  emails,
);
```

```typescript [apps/app/nuxt.config.ts]
export default defineNuxtConfig({
  hub: {
    blob: true,
    kv: true,
    cache: true,
  },
});
```

## What's actually used

- **`hubBlob()`**: Almacenamiento de archivos R2. Utilizado para imágenes de perfil y logos de equipos (consulte [Almacenamiento](/docs/saas-starter-kit/features/storage)).
- **`hubKV()`**: Cloudflare KV. Empleado para ventanas de límite de tasa (`apps/app/server/utils/rate-limit.ts`) y pequeños valores en caché como el ID de configuración de cancelación de Stripe.
- **`CACHE`**: Aprovisionado (`hub: { cache: true }`), pero nada en la aplicación llama a `hubCache()` actualmente. Queda disponible para cuando una ruta requiera la capa de caché de Nitro.

**No utilizado en absoluto:** `hubDatabase()`. La base de datos de Nuxfire es Postgres mediante Cloudflare Hyperdrive (consulte [Base de Datos](/docs/saas-starter-kit/features/database)), una separación intencional del módulo de D1 de NuxtHub, para que la app pueda apuntar a cualquier Postgres estándar en lugar de estar atada a D1.

## Local development

Dado que la aplicación se construye sobre el módulo de Nuxt de `@nuxt-hub/core`, el panel de NuxtHub Dev Tools funciona localmente durante `bun run app` (que usa wrangler/miniflare para emular los enlaces de Cloudflare), sin necesidad de crear una cuenta en NuxtHub ni desplegar a través de él.
