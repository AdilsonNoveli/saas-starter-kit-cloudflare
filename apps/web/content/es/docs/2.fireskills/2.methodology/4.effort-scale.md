En Fireskills, el **Effort** es una nota numérica de **1 a 10** asignada a toda especificación. A diferencia de los puntos ágiles tradicionales o las estimaciones en horas, el Effort mide explícitamente la **carga de razonamiento cognitivo, el riesgo arquitectónico y la complejidad de ejecución** — nunca días de calendario ni plazos.

---

## Los 4 perfiles de complejidad

| Rango de Effort | Perfil | Alcance típico | Perfil de razonamiento del agente |
|---|---|---|---|
| **1 – 2** | `light` | Ajustes pequeños, ediciones de texto, correcciones de bugs localizadas, pequeños retoques en un componente. | Ejecución rápida, poco razonamiento arquitectónico necesario. |
| **3 – 6** | `standard` | Porciones de funcionalidad típicas: un nuevo procedure de tRPC, una tabla nueva en Drizzle, una página de CRUD o un formulario de UI. | Razonamiento estándar en varios pasos, requiere el especialista del dominio. |
| **7 – 8** | `high` | Funcionalidades entre layers: bindings de Worker, consumidor de cola, integración de billing, RBAC complejo. | Planificación arquitectónica profunda, verificación rigurosa en varios archivos. |
| **9 – 10** | `maximum` | Refactorización de infraestructura central, reforma del sistema de autenticación, migración de datos a escala. | Presupuesto máximo de razonamiento, evaluación adversarial (`fireskill-the-fool`). |

---

## Campos de metadatos de la cabecera

La cabecera de la especificación registra tres campos de esfuerzo estrechamente ligados:

```markdown
| Campo | Valor |
| --- | --- |
| Effort | 4 |
| Effort updated at | 2026-09-18T16:15:00.000Z |
| Effort rationale | Adds a Stripe webhook handler and idempotent subscription updates |
```

---

## Actualizar el Effort desde la CLI

El Effort debe actualizarse siempre que un nuevo descubrimiento, la planificación de tareas o la implementación revelen una complejidad relevante que antes se desconocía.

Usa el comando `fireskill` de la CLI:

```bash
bun run fireskill effort <id> <1-10> --reason "<rationale>"
```

### Ejemplo:
```bash
bun run fireskill effort 0042 6 --reason "Requires custom Drizzle migration and Cloudflare KV session cache invalidation"
```

El comando actualiza `Effort`, define `Effort updated at` con la marca de tiempo ISO 8601 actual y registra el `Effort rationale` en la cabecera. El identificador es el número de la spec o el `<NNNN>-<slug>` completo; una nota fuera de 1–10, o una justificación vacía, se rechaza.

---

## Cómo usarlo

La nota es una guía de cuánto cuidado necesita una porción. No inicia ninguna skill por sí sola. Como regla práctica, para una spec con Effort 7 o más, pide una revisión adversarial (`$fireskill-the-fool`) antes de aprobar el Definition Gate, y una decisión colegiada (`$fireskill-the-jury`) para las decisiones de arquitectura irreversibles. `$fireskill-interviewer` reevalúa la nota cuando una conversación cambia la capacidad necesaria.
