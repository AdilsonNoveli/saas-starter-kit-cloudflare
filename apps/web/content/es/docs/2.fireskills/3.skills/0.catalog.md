Fireskills ofrece 23 skills especializadas que guían a los agentes de IA y a los equipos de ingeniería por todas las fases del ciclo de vida de la ingeniería de software.

---

## Matriz completa de skills

### Skills del ciclo de vida principal

| Skill | Fase / Acto | Finalidad principal |
|---|---|---|
| [`fireskill-01-inbox`](/docs/fireskills/skills/act-1-define) | Acto I: Definir | Captura ideas en bruto y peticiones de funcionalidad en `specs/inbox/` sin interrupciones. |
| [`fireskill-02-backlog`](/docs/fireskills/skills/act-1-define) | Acto I: Definir | Crea un ítem de backlog a partir de una idea y lo refina con preguntas numeradas. |
| [`fireskill-03-specify`](/docs/fireskills/skills/act-1-define) | Acto I: Definir | Redacta el `spec.md` canónico inicial con requisitos y escenarios BDD en Gherkin. |
| [`fireskill-04-validate`](/docs/fireskills/skills/act-1-define) | Acto I: Definir | Valida la completitud de la definición, la cobertura de AC y sella el Definition Gate. |
| [`fireskill-05-tasks`](/docs/fireskills/skills/act-2-design-prove) | Acto II: Diseñar y Probar | Descompone las especificaciones en tareas atómicas con checklists obligatorios de 6 ítems. |
| [`fireskill-06-tdd-bdd`](/docs/fireskills/skills/act-2-design-prove) | Acto II: Diseñar y Probar | Deriva casos Vitest de los escenarios BDD y observa un RED válido. |
| [`fireskill-07-implement`](/docs/fireskills/skills/act-3-deliver) | Acto III: Entregar | Implementa código de producción con la disciplina RED → GREEN → REFACTOR y sella el Delivery Gate. |
| [`fireskill-documentator`](/docs/fireskills/skills/act-3-deliver) | Acto III: Entregar | Reconstruye `docs/` y `.fireskills/PACKAGES.md` a partir del código. |
| [`fireskill-progress`](/docs/fireskills/skills/act-3-deliver) | Acto III: Entregar | Visualiza el progreso actual de todas las especificaciones, estados y milestones. |

### Skills de gobierno y descubrimiento

| Skill | Categoría | Finalidad principal |
|---|---|---|
| [`fireskill-setup`](/docs/fireskills/skills/governance-and-decisions) | Gobierno | Reconcilia el contexto de `.fireskills/`, pregunta tu nivel de conocimiento y los temas sin respuesta, y ejecuta el monitor. |
| [`fireskill-update-spec`](/docs/fireskills/skills/governance-and-decisions) | Actualización del ciclo de vida | Gestiona los cambios en una spec que ya pasó el Definition Gate, reabriendo solo los actos y gates necesarios. |
| [`fireskill-interviewer`](/docs/fireskills/skills/governance-and-decisions) | Descubrimiento | Permite explorar conversando las especificaciones en cualquier estado activo. |
| [`fireskill-data-discovery`](/docs/fireskills/skills/governance-and-decisions) | Datos y schema | Investiga qué necesita guardar el producto en lenguaje cotidiano y sincroniza `DATABASE.md`. |
| [`fireskill-lessons`](/docs/fireskills/skills/governance-and-decisions) | Memoria y aprendizaje | Registra reglas preventivas a partir de fallos reales en `.fireskills/lessons.json` y `LESSONS.md`. |
| [`fireskill-the-jury`](/docs/fireskills/skills/governance-and-decisions) | Toma de decisiones | Deliberación colegiada de un panel de 3 a 5 subagentes para decisiones de alto impacto. |
| [`fireskill-the-fool`](/docs/fireskills/skills/governance-and-decisions) | Revisión adversarial | Somete las especificaciones a pruebas de estrés para exponer supuestos frágiles, casos límite y modos de fallo. |
| [`fireskill-the-judge`](/docs/fireskills/skills/governance-and-decisions) | Code review | Code review basado en evidencia que analiza PRs y diffs frente a los contratos del repositorio. |

### Skills de milestones y auxiliares

|---|---|---|
| [`fireskill-mvp-milestone-interviewer`](/docs/fireskills/skills/governance-and-decisions) | Milestones | Define las milestones del Producto Mínimo Viable mediante estados demostrables y comprobables. |
