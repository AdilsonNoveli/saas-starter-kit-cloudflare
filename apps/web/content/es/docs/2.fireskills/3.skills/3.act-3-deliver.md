El Acto III convierte el plan en código verificado y termina en el **Delivery Gate**.

| Skill | Crea o modifica | Página del paso |
|---|---|---|
| `fireskill-07-implement` | código de producción, pruebas, checklists y evidencia en la spec, `.fireskills/*` | [Paso 7](/docs/fireskills/getting-started/step-implement) |
| `fireskill-documentator` | `docs/` (raíz del repositorio) y `.fireskills/PACKAGES.md` | [Paso 8](/docs/fireskills/getting-started/step-documentator) |
| `fireskill-progress` | nada (proyecta el estado) | [Otros puntos de entrada](/docs/fireskills/getting-started/other-entry-points) |

## `fireskill-07-implement`

Ejecuta una tarea a la vez (`next_task.mjs` la elige), cargando el especialista del área antes de tocar código, y marca cada ítem del checklist a medida que aparece la evidencia. Mueve la spec a `in-progress` al inicio y a `review` cuando el Delivery Gate pasa; `$fireskill-04-validate` la acepta entonces en `completed`. Comprobación de cierre:

```bash
bun run test                       # repository root
cd apps/app
bun run typecheck
bunx vue-tsc --noEmit -p server/tsconfig.json
```

más el monitor de contexto y `build_documentation.mjs --check`. `bun run typecheck` es un script de `apps/app`; la raíz no tiene ninguno.

## `fireskill-documentator`

Reconstruye `docs/` y `.fireskills/PACKAGES.md` a partir del código con `build_documentation.mjs` (`--check` demuestra que está al día). Se ejecuta después de toda tarea `[CODE]`. No escribe la documentación pública de este sitio (`apps/web/content/docs/`).

## `fireskill-progress`

Proyecta el estado; no cambia ningún gate ni checkbox.

```bash
bun run fireskill progress
```

Salida real en un proyecto con una spec:

```text
Summary	1 specs	0/6 tasks	0/55 items	0%
0001-convite-de-membros-por-e-mail	Draft	0/6 tasks	0/55 items	0%
```

`--json` y `--watch` están disponibles. La skill también ofrece `progress.mjs` y `analyze_context.mjs` (coste de contexto de una spec, siempre etiquetado `estimated`, salvo que se indique el uso medido).
