Más allá de las herramientas específicas de la stack, Fireskills equipa a los agentes de IA con 23 especialistas de dominio que encarnan prácticas de ingeniería de software empresarial.

---

## Lenguajes y modelado de datos

| Especialista | Alcance y competencia |
|---|---|
| `fireskill-specialist-typescript` | Modelado avanzado del sistema de tipos, utilidades genéricas, configuraciones estrictas del compilador y validación de schema type-safe. |
| `fireskill-specialist-postgres` | Diseño relacional en PostgreSQL, índices compuestos, optimización de queries, control de concurrencia y migraciones sobre Hyperdrive. |
| `fireskill-specialist-data-modeling` | Ciclos de vida de entidades relacionales, formas normales, integridad transaccional y contratos de schema persistentes en Drizzle. |
| `fireskill-specialist-domain-modeling` | Domain-Driven Design (DDD), lenguaje ubicuo, agregados de negocio, eventos de dominio y bounded contexts entre layers. |

---

## Arquitectura y diseño de APIs

| Especialista | Alcance y competencia |
|---|---|
| `fireskill-specialist-software-architecture` | Imposición de límites, inversión de dependencias, atributos de calidad no funcionales y Architectural Decision Records (ADRs). |
| `fireskill-specialist-web-api-design` | Contratos de API resilientes, patrones de envoltorio de errores, paginación por cursor, mutaciones idempotentes y compatibilidad hacia atrás. |
| `fireskill-specialist-prototyping` | Spikes técnicos rápidos y desechables para reducir incertidumbres arquitectónicas antes de la especificación normativa. |
| `fireskill-specialist-technical-research` | Investigación rigurosa en fuentes primarias y recopilación de evidencia empírica sin afirmaciones alucinadas. |

## Seguridad, rendimiento y calidad

| Especialista | Alcance y competencia |
|---|---|
| `fireskill-specialist-application-security` | Mitigación del OWASP Top 10, bóvedas de secrets, políticas de CSRF/CORS, sanitización de entradas y verificación de firma de webhooks (Stripe/Paddle). |
| `fireskill-specialist-performance-engineering` | Presupuestos de ejecución de Cloudflare Workers, profiling de tiempo de CPU, optimización de Core Web Vitals, división de bundles y caché en el borde. |
| `fireskill-specialist-observability` | Logs estructurados, tracing, telemetría de errores, SLOs y alertas, aplicados a Cloudflare Workers. |
| `fireskill-specialist-debugging` | Diagnóstico de causa raíz guiado por hipótesis, depuración por búsqueda binaria, scripts de reproducción y análisis de fallos intermitentes. |
| `fireskill-specialist-code-review` | Revisión sistemática de diffs evaluando los cambios frente a los contratos del repositorio, casos límite, type safety y cobertura de pruebas. |

## Diseño, UX y accesibilidad

| Especialista | Alcance y competencia |
|---|---|
| `fireskill-specialist-tailwind-css` | Tokens de Tailwind CSS, evitar valores arbitrarios, breakpoints responsivos, temas de color dinámicos y composición de utilidades. |
| `fireskill-specialist-design-system` | Gobierno del design system: mapeo de tokens, `sharedUiConfig`, `enterpriseTableUi` y patrones de dashboards SaaS. |
| `fireskill-specialist-ui-design` | Composición de interfaz: layouts, vistas, tablas de datos, formularios, estados vacíos y jerarquías visuales en Vue SFC. |
| `fireskill-specialist-ux-design` | Mapeo de recorridos de usuario, divulgación progresiva, reducción de carga cognitiva y flujos de recuperación de errores. |
| `fireskill-specialist-interface-experience` | Análisis de flujos de varias pantallas, estructuras de navegación, patrones de interacción de CRUD y ergonomía de formularios responsivos. |
| `fireskill-specialist-web-accessibility` | Cumplimiento de WCAG 2.1 AA, atributos ARIA, trampas de navegación por teclado, gestión del foco y compatibilidad con lectores de pantalla mediante Reka UI. |

## Entrega y operaciones de Git

| Especialista | Alcance y competencia |
|---|---|
| `fireskill-specialist-delivery-engineering` | Integración continua, pipelines de deploy en staging, despliegues de migraciones de base de datos y recuperación ante desastres. |
| `fireskill-specialist-versioning` | El archivo `VERSION` de la raíz, incrementos SemVer y la etiqueta Git `v<VERSION>`. Nuxfire no tiene imágenes Docker, registry ni changelog. |
| `fireskill-specialist-gitflow` | Estrategias de ramas (`main`, `develop`, ramas de funcionalidad), higiene de commits y convenciones de pull request. |
| `fireskill-specialist-merge-conflict-resolution` | Resolución segura de conflictos de merge y rebase en Git preservando la intención original del autor y con las pruebas de regresión en verde. |
