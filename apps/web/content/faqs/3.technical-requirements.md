---
title: "What technical stack and experience do I need?"
---

Nuxfire is built with modern TypeScript, Nuxt 4, Vue 3, and declarative SST v4 for Cloudflare.

- **For Senior Developers:** You get clean modular layers, end-to-end type safety with tRPC, and Drizzle ORM—with zero vendor lock-in and zero runtime framework bloat.
- **For AI Builders & Vibe Coders:** If you build using Cursor, Claude Code, or v0, Nuxfire provides the ultimate architectural context. Strict TypeScript contracts, typed schemas, and isolated Nuxt Layers allow AI models to generate reliable, production-ready features on the first attempt without breaking existing logic.
