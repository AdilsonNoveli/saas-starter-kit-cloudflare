---
title: "How customizable is the starter kit?"
---

Nuxfire provides 100% full source code ownership. You receive the raw, unminified code without proprietary CLI wrappers, hidden npm packages, or black-box dependencies.

- Freely customize or rebrand the entire Tailwind CSS design system and tokens.
- Add, modify, or remove modular layers (`admin`, `billing`, `teams`, `notifications`, `kanban`).
- Extend the Drizzle ORM database schema and generate migrations automatically.
- Implement your own custom business logic with full architectural freedom.
