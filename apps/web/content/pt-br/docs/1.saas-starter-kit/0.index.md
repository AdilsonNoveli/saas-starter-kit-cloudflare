O **SaaS Starter Kit** é um starter kit Nuxt pronto para produção e de nível corporativo construído para a Cloudflare — faça deploy direto para produção, sem scaffolds vazios para preencher primeiro.

---

## Principais Recursos

### 1. E-mails

- **Templates**: [React Email](https://react.email/), baseados em componentes.
- **Worker agnóstico de provedor**: Resend, Amazon SES, Mailgun, Sparkpost ou SMTP customizado.

### 2. Autenticação (Nuxfire Auth)

Um servidor de autenticação independente (OpenAuth.js), implantável para proteger qualquer frontend ou backend, em `auth.SEU-DOMINIO.com`:

- Login social com Google e GitHub.
- Login via código e login com e-mail/senha, com recuperação de senha.
- Extensível com novos métodos de autenticação.

### 3. Infraestrutura

Infraestrutura como código — crie e desmonte quantos ambientes precisar, em qualquer conta da Cloudflare.

### 4. Site de Conteúdo

Hospedado em `SEU-DOMINIO.com`: landing page, blog, documentação e busca em todo o site, tudo integrado.

### 5. Painel da Aplicação

Implantado em `app.SEU-DOMINIO.com`:

- Tarefas assíncronas via Cloudflare Queues e gatilhos cron.
- Cobrança via Stripe e Paddle.
- Notificações em tempo real via WebSockets.
- Equipes — membros, convites, controle de acesso baseado em funções (RBAC).

### 6. Servidor WebSockets

Comunicação em tempo real sobre Cloudflare Durable Objects, em `websockets.SEU-DOMINIO.com`.

### 7. Recursos Adicionais

- Armazenamento de blobs (R2) via `@nuxt-hub/core` — o banco de dados principal é Postgres via Hyperdrive, e não um store gerenciado pelo NuxtHub (consulte [Banco de Dados](/docs/saas-starter-kit/features/database)).
- Internacionalização (i18n).
- SEO integrado.
