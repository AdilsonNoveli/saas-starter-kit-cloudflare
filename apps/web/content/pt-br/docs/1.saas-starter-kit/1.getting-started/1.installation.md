## 1. Install Bun

```bash
curl -fsSL https://bun.sh/install | bash
```

No Windows sem WSL: `npm install -g bun`.

**Prompt para agentes de IA:**
```text

Check for Bun with bun --version. If it's missing, run
curl -fsSL https://bun.sh/install | bash (Windows without WSL:
npm install -g bun), then confirm the version again before continuing.

```

## 2. Get the codebase and install

Baixe o monorepo do Nuxfire diretamente da sua **Área de Membros** após a compra, extraia-o para o diretório de sua preferência e instale as dependências:

```bash
cd nuxfire
bun install
```

O primeiro `bun install` leva alguns minutos — ele não travou. Rode-o sempre dentro da pasta extraída e nunca copie uma pasta `node_modules` de outra máquina ou projeto: os links dos workspaces (`@nuxfire/*`) podem quebrar, e a verificação prévia do deploy ([Deploy](/docs/saas-starter-kit/getting-started/deploy)) avisa se isso acontecer.

*(Opcional: Inicialize seu próprio repositório Git privado para controle de versão)*:

```bash
git init
git add .
git commit -m "Initial commit from Nuxfire"
```

As migrações já estão versionadas em `apps/functions/src/database/migrations/`. Você só precisa gerar novas migrações se alterar `apps/functions/src/database/core-schema.ts` ou o `server/database/schema.ts` de qualquer layer (`drizzle.config.ts` lê ambos, e não o barrel `schema.ts` — esse arquivo apenas os reexporta):

```bash
cd apps/functions
DATABASE_HOST=... DATABASE_PORT=5432 DATABASE_USER=... DATABASE_PASSWORD=... DATABASE_NAME=... \
  bunx drizzle-kit generate
```

(Sem `DATABASE_URL` — `drizzle.config.ts` lê host/port/user/password/name separadamente, para que você nunca precise montar ou escapar uma URL contendo senha.)

**Prompt para agentes de IA:**
```text
In the extracted nuxfire project root, run: bun install
Only run bunx drizzle-kit generate (from apps/functions) if
core-schema.ts or a layer's server/database/schema.ts changed — ask
the user for their real DATABASE_HOST/PORT/
USER/PASSWORD/NAME first, never invent placeholder values.
```
