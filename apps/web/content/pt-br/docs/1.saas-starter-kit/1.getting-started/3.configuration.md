Escolha suas flags de recursos. Desative em `flags` qualquer integração que você não for usar (Stripe, Paddle, websockets, filas, provedores de e-mail desnecessários) — isso reduz a quantidade de secrets que você precisará configurar.

Sua identidade **não** é definida neste arquivo: o nome da marca, seu domínio de produção e o e-mail completo do remetente são as variáveis `BRAND_*` da seção Branding do arquivo de env do seu estágio — o único lugar onde elas vivem. Preencha-as junto com suas credenciais em [Secrets](/docs/saas-starter-kit/getting-started/secrets); [Variáveis de Ambiente](/docs/saas-starter-kit/getting-started/environment-variables) explica cada uma.

```typescript [config.ts]
export const flags: {
  stripe?: boolean;
  paddle?: boolean;
  googleAuth?: boolean;
  githubAuth?: boolean;
  resend?: boolean;
  mailgun?: boolean;
  ses?: boolean;
  sparkPost?: boolean;
  smtp?: boolean;
  websockets?: boolean;
  cron?: boolean;
  jobsQueue?: boolean;
} = {
  stripe: true,
  paddle: true,
  githubAuth: true,
  googleAuth: true,
  resend: true,
  websockets: true,
  jobsQueue: true,
};
```

O mesmo arquivo também declara `layers` — independente de `flags`, diz respeito aos Nuxt Layers compilados dentro de `apps/app`, e não aos recursos provisionados na Cloudflare:

```typescript [config.ts]
export const layers = {
  // Always extended, never toggleable — every tenant needs them.
  core: ["teams", "notifications", "admin", "account"] as string[],

  // Toggleable per build/deploy. `false` drops the layer's pages, components
  // and Nuxt config from the bundle, and its migrations from the deploy.
  features: {
    kanban: true,
    billing: true,
  } as const,
};
```

`core` lista os quatro layers de domínio de negócios que todo deploy entrega (`teams`, `notifications`, `admin`, `account`) — consulte [Estrutura do Projeto](/docs/saas-starter-kit/getting-started/project-structure). `features` é onde layers opcionais como `kanban` e `billing` podem ser ativados ou desativados para um build.

**Prompt para agentes de IA:**
```text
Open config.ts. Ask the user which integrations they want before
editing the flags object — do not guess or invent any of these values.
The domain, sender email and brand name are not in this file: they are
the BRAND_* variables the user fills in their own env file — never
edit or fill those in yourself. Only touch layers.features if the user explicitly asks to
disable an optional layer (e.g. kanban) — never touch layers.core.
```
