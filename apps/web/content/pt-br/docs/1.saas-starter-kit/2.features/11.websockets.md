---
title: "WebSockets"
description: "Uma implementação pub/sub de WebSockets baseada em Cloudflare Durable Objects, protegida pela flag websockets."
---

Atualizações em tempo real executam sobre Cloudflare Workers e Durable Objects, sob a flag `websockets` no `config.ts`.

## Architecture

- Cliente WebSocket frontend: `apps/app/app/plugins/websockets.client.ts` (um plugin complementar, `ws-notifications.client.ts`, conecta isso ao recurso de notificações)
- Servidor WebSocket backend: `apps/functions/src/websockets.js`
- Infraestrutura: `infra/websockets.ts`

## Usage

### Frontend

O cliente WebSocket é um plugin Nuxt, disponível nos componentes via `$ws`:

```ts
// In your component
const { $ws } = useNuxtApp();

// Subscribe to topics
$ws.on("user.123", (data) => {
  // Handle topic payload
  console.log("Got update:", data);
});

// Cleanup when done
onUnmounted(() => {
  $ws.off("user.123");
});
```

O cliente automaticamente:

- Autentica-se usando um ticket WebSocket de curta duração (`/api/auth/ws-ticket`) em vez do token de sessão de longa duração — o cabeçalho `sec-websocket-protocol` é a única maneira de autenticar uma conexão WebSocket no navegador e pode ser lido pelo JS da página, portanto o token de acesso real nunca é exposto lá.
- Reconecta-se em caso de quedas de conexão.
- Reassina os tópicos após a reconexão.

### Backend

Publique mensagens para tópicos a partir de um procedimento tRPC via `ctx.sendWebsocketsEvent`:

```typescript
async ({ ctx: { user, sendWebsocketsEvent }, input }) => {
  // ...create notification in database...
  await sendWebsocketsEvent(
    user.id, // topic
    { type: "notification", payload: notification },
  );
};
```

## Security

- A autenticação usa um ticket de curta duração, assinado com um segredo compartilhado unicamente entre o Worker App e o Worker de Websockets (`WsTicketSecret`, `infra/websockets.ts`) — nunca o token de sessão do OpenAuth.
- A autorização de tópicos é determinada pelo que a aplicação decide publicar em determinado tópico — não há ACL integrada por tópico, portanto defina nomes de tópicos (por exemplo, `user.<id>`) restritos a quem deve legitimamente recebê-los.

## Configuration

Habilite WebSockets definindo a flag `websockets`:

```ts [config.ts]
export const flags = {
  // ...
  websockets: true,
};
```

Isso implanta o Worker de WebSockets (apoiado por um Durable Object) e o vincula ao aplicativo.
