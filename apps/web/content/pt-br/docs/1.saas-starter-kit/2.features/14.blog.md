O Nuxfire vem com um sistema de blog minimalista construído com o [Nuxt Content](https://content.nuxt.com/). Adicione arquivos markdown para começar a publicar.

## What's Included

- Páginas mínimas de índice e posts de blog
- Integração com busca em todo o site
- Otimização para SEO
- Design responsivo
- Suporte a modo escuro

## File Structure

Os artigos do blog residem em `apps/web/content/blog`, como uma coleção própria do Nuxt Content (`apps/web/content.config.ts`) com campos obrigatórios `date` e `author` no frontmatter de cada postagem:

```yaml
---
title: "Post title"
date: "2026-01-15"
author: "Your Name"
---
```
