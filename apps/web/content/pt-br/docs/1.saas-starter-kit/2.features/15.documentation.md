O site de documentação do Nuxfire (o que você está lendo agora) é construído sobre o [Nuxt Content](https://content.nuxt.com/).

À medida que você adiciona recursos, insira novos arquivos markdown sob `apps/web/content/docs` e eles serão incluídos automaticamente na navegação e na busca — o prefixo numérico em cada arquivo/pasta (`1.getting-started`, `2.features`, ...) controla a ordenação e é removido da URL gerada.

## What's Included

- Nuxt Content, configurado como uma coleção `docs` (`apps/web/content.config.ts`) ao lado das coleções separadas `blog`, `faqs` e `legal`.
- Tematização de componentes Prose, para que o markdown renderizado combine com o restante do site.
- Busca em texto completo.
- Navegação otimizada para dispositivos móveis.
- Suporte a modo escuro.

## Prose Components

Elementos em Markdown são estilizados através do mecanismo de substituição do próprio Nuxt Content — um componente nomeado `Prose<Tag>` em `apps/web/app/components/content/` substitui a renderização padrão daquela tag, aplicado automaticamente sem necessidade de marcação individual por página:

```
apps/web/app/components/content/
  ProseA.vue        ProseH1.vue ... ProseH6.vue    ProseTable.vue
  ProseCode.vue      ProseBlockquote.vue            ProseUl.vue / ProseOl.vue / ProseLi.vue
  ProseCodeInline.vue  CodeCopy.vue   Center.vue     ...
```

## Search

A busca em texto completo é incluída pronta para uso, alimentada pelo Nuxt Content.

## Customization

```typescript [apps/web/nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    build: {
      markdown: {
        highlight: {
          langs: ["ts", "vue", "bash"],
          theme: {
            default: "github-light",
            dark: "github-dark",
            sepia: "monokai",
          },
        },
      },
    },
  },
});
```
