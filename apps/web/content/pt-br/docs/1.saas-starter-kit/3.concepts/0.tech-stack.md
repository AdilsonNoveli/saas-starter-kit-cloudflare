## Auth & authorization

| | Purpose |

## Infrastructure — Cloudflare, via SST

Implantado inteiramente como código com [SST](https://sst.dev) (`sst` 4.14.0) e seus provedores Pulumi (`cloudflare` 6.20.0, `command` 1.0.1, `random` 4.17.0) — consulte [SST.dev](/docs/saas-starter-kit/concepts/sst).

| Cloudflare service | Used for |
|---|---|
| Workers | Todas as aplicações implantadas (App, Auth, Web, Emails, Websockets, consumidores job/DLQ, Cron) |
| Hyperdrive | Agrupamento (pooling) de conexões Postgres a partir de Workers |
| KV | Credenciais de autenticação (`AuthKV`), contadores de rate limit, pequenos valores em cache |
| R2 (via `@nuxt-hub/core`) | Armazenamento de blobs — fotos de perfil, logotipos de equipes |
| D1 | Banco de dados de conteúdo do site de docs (busca em `apps/web`) — exigido pelo `@nuxt/content` na Cloudflare |
| Queues | Processamento de tarefas assíncronas, além de fila de mensagens com falha (dead-letter) |
| Durable Objects | O servidor de WebSockets |
| Cron Triggers | Tarefas agendadas |
| Custom Domains | Domínio público de cada Worker, com DNS configurado automaticamente |
