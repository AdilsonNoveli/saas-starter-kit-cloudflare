**Skill:** `fireskill-01-inbox` · **Faz perguntas:** não · **Cria:** `specs/inbox/<AAAA-MM-DD-HHMMSS>-<slug>.md`

## Quando usar

Você tem uma ideia bruta, um pedido de alguém ou um relato de bug, e quer guardá-lo agora sem ser interrogado.

## O que digitar

```text
Use $fireskill-01-inbox para registrar este texto imediatamente, sem perguntas, em specs/inbox/.

Donos de equipe devem convidar membros por e-mail; o link expira em 48 horas.
```

A primeira linha é o prompt oficial. Escreva o seu texto embaixo dela.

## O que o agente faz

1. Verifica em silêncio se há credenciais, tokens, chaves privadas e dados pessoais evidentes. Se encontrar algum, **não salva o arquivo**: ele pede que você remova o dado sensível e envie a ideia de novo.
2. Roda `fireskills/skills/fireskill-01-inbox/scripts/capturar_inbox.mjs` com um `--title` e o seu texto como `--input`.
3. Preserva a sua redação como está e guarda um SHA-256 do original.
4. Acrescenta uma análise inicial (problema, pessoas afetadas, resultado esperado, riscos) separada em declaração, **inferência** e **a revisar**, nunca como decisão. Onde o texto não dá base, escreve `Não identificado no texto original.`
5. Não pergunta nada, não trava por duplicata ou falta de contexto, e informa só o caminho do arquivo e um resumo curto.

Você não escreve esse arquivo à mão: o template tem uma estrutura fixa que as skills seguintes leem.

## Resultado

`specs/inbox/2026-09-18-174245-convite-de-membros-por-e-mail.md`, começando com:

```markdown
# Inbox: Convite de membros por e-mail

| Metadado | Valor |
| --- | --- |
| Status | Capturada |
| Capturada em | 2026-09-18T20:42:45Z |
| Slug | convite-de-membros-por-e-mail |
| Origem | Input do usuário |
| Processamento | Análise inicial sem perguntas |
| Integridade do original | SHA-256 `556c4ccafe2e…` |
| Backlog derivado | Nenhum |
| Spec derivada | Nenhuma |

## Texto original
```

Um arquivo de inbox nunca é alterado nem apagado pelas etapas seguintes; o backlog e a spec apenas apontam de volta para ele.

## Próximo

A skill de inbox **não** inicia a próxima etapa sozinha. Para refinar a ideia, digite o prompt da [Etapa 2: Backlog](/docs/fireskills/getting-started/step-backlog). Você também pode parar aqui e deixar a ideia em `specs/inbox/` para depois.
