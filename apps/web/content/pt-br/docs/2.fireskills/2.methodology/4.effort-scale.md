No Fireskills, o **Effort** é uma nota numérica de **1 a 10** atribuída a toda especificação. Diferente de pontos ágeis tradicionais ou estimativas em horas, o Effort mede explicitamente a **carga de raciocínio cognitivo, o risco arquitetural e a complexidade de execução** — nunca dias de calendário ou prazos.

---

## Os 4 Perfis de Complexidade

| Faixa de Effort | Perfil | Escopo típico | Perfil de raciocínio do agente |
|---|---|---|---|
| **1 – 2** | `light` | Ajustes pequenos, edições de texto, correções de bug localizadas, pequenos ajustes em um componente. | Execução rápida, pouco raciocínio arquitetural necessário. |
| **3 – 6** | `standard` | Fatias de feature típicas: uma nova procedure tRPC, uma tabela nova no Drizzle, uma página de CRUD ou um formulário de UI. | Raciocínio padrão em várias etapas, exige o especialista do domínio. |
| **7 – 8** | `high` | Features entre layers: bindings de Worker, consumidor de fila, integração de billing, RBAC complexo. | Planejamento arquitetural profundo, verificação rigorosa em vários arquivos. |
| **9 – 10** | `maximum` | Refatoração de infraestrutura central, reformulação do sistema de autenticação, migração de dados em escala. | Orçamento máximo de raciocínio, avaliação adversarial (`fireskill-the-fool`). |

---

## Campos de metadados do cabeçalho

O cabeçalho da especificação acompanha três campos de esforço intimamente ligados:

```markdown
| Campo | Valor |
| --- | --- |
| Effort | 4 |
| Effort updated at | 2026-09-18T16:15:00.000Z |
| Effort rationale | Adds a Stripe webhook handler and idempotent subscription updates |
```

---

## Atualizando o Effort pela CLI

O Effort deve ser atualizado sempre que uma nova descoberta, o planejamento de tarefas ou a implementação revelarem uma complexidade relevante que antes era desconhecida.

Use o comando `fireskill` da CLI:

```bash
bun run fireskill effort <id> <1-10> --reason "<rationale>"
```

### Exemplo:
```bash
bun run fireskill effort 0042 6 --reason "Requires custom Drizzle migration and Cloudflare KV session cache invalidation"
```

O comando atualiza o `Effort`, define o `Effort updated at` com o timestamp ISO 8601 atual e registra o `Effort rationale` no cabeçalho. O identificador é o número da spec ou o `<NNNN>-<slug>` completo; uma nota fora de 1–10, ou uma justificativa vazia, é rejeitada.

---

## Como usar

A nota é um guia de quanto cuidado uma fatia precisa. Ela não inicia nenhuma skill sozinha. Como regra prática, para uma spec com Effort 7 ou mais, peça uma revisão adversarial (`$fireskill-the-fool`) antes de aprovar o Definition Gate, e uma decisão colegiada (`$fireskill-the-jury`) para escolhas de arquitetura irreversíveis. O `$fireskill-interviewer` reavalia a nota quando uma conversa muda a capacidade necessária.
