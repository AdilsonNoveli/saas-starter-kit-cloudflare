Especificações individuais não existem isoladas. O Fireskills oferece ferramentas de governança de alto nível para organizar fatias de feature em releases coerentes, produtos mínimos viáveis (MVP) e roadmaps evolutivos de longo prazo.

---

## A Hierarquia de Milestones

```text
Product Vision
  └── Milestone (e.g., MVP v1.0)
        ├── Spec 0001: Authentication & Workspace Setup
        ├── Spec 0002: Core Domain Resource Management
        └── Spec 0003: Stripe Subscription Billing
```

---

## Skills de Governança de Milestones

O Fireskills oferece três skills especializadas de governança para definir e manter releases:

### 1. `fireskill-mvp-milestone-interviewer`
Foca em definir o Produto Mínimo Viável inicial por meio de estados de usuário demonstráveis e testáveis. Evita o crescimento descontrolado de escopo investigando rigorosamente o que é essencial para o produto funcionar.

### 2. `fireskill-roadmap-milestone-interviewer`
Usada para a evolução pós-MVP. Depois que a milestone do MVP é aceita, esta skill organiza os pedidos de feature seguintes em milestones em estágios, com impacto de negócio claro.

### 3. `fireskill-milestone-governor`
Mantém a integridade relacional entre especificações, milestones e a projeção de roadmap `specs.md` gerada, sem alterar as notas escritas por humanos.

## Sincronizando Milestones pela CLI

Para regenerar e sincronizar a visão macro do roadmap entre todas as especificações, rode:

```bash
bun run fireskill milestones sync
```

Este comando:
1. Lê as specs (todas as pastas de estado) e os itens de backlog.
2. Atualiza os blocos derivados do `specs.md` (na raiz do repositório) e de `specs/milestones/<ID>.md`, com o progresso de cada milestone.
3. Deixa intocado o texto escrito por humanos fora desses blocos.

## Integração com Rastreador de Issues Externo (ClickUp)

Ao gerenciar tarefas entre times distribuídos, as especificações podem se vincular diretamente a ferramentas externas de gestão de projetos como o ClickUp:

```markdown
| Campo | Valor |
| --- | --- |
| ClickUp Task | https://app.clickup.com/t/86a1b2c3d |
```

O campo do cabeçalho faz parte do template. As skills `clickupfy-*` que sincronizariam status e Effort com o ClickUp **não** fazem parte deste repositório; sem elas o campo é só um link, e a spec local é sempre a fonte de verdade.
