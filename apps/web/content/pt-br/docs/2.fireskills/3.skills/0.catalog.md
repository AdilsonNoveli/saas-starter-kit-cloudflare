O Fireskills oferece 23 skills especializadas que guiam agentes de IA e times de engenharia por todas as fases do ciclo de vida da engenharia de software.

---

## Matriz Completa de Skills

### Skills do Ciclo de Vida Principal

| Skill | Fase / Ato | Finalidade principal |
|---|---|---|
| [`fireskill-01-inbox`](/docs/fireskills/skills/act-1-define) | Ato I: Definir | Captura ideias brutas e pedidos de feature em `specs/inbox/` sem interrupção. |
| [`fireskill-02-backlog`](/docs/fireskills/skills/act-1-define) | Ato I: Definir | Cria um item de backlog a partir de uma ideia e o refina por perguntas numeradas. |
| [`fireskill-03-specify`](/docs/fireskills/skills/act-1-define) | Ato I: Definir | Redige o `spec.md` canônico inicial com requisitos e cenários BDD em Gherkin. |
| [`fireskill-04-validate`](/docs/fireskills/skills/act-1-define) | Ato I: Definir | Valida a completude da definição, a cobertura de AC e sela o Definition Gate. |
| [`fireskill-05-tasks`](/docs/fireskills/skills/act-2-design-prove) | Ato II: Projetar e Provar | Decompõe as especificações em tarefas atômicas com checklists obrigatórios de 6 itens. |
| [`fireskill-06-tdd-bdd`](/docs/fireskills/skills/act-2-design-prove) | Ato II: Projetar e Provar | Deriva casos Vitest dos cenários BDD e observa um RED válido. |
| [`fireskill-07-implement`](/docs/fireskills/skills/act-3-deliver) | Ato III: Entregar | Implementa código de produção na disciplina RED → GREEN → REFACTOR e sela o Delivery Gate. |
| [`fireskill-documentator`](/docs/fireskills/skills/act-3-deliver) | Ato III: Entregar | Reconstrói `docs/` e `.fireskills/PACKAGES.md` a partir do código. |
| [`fireskill-progress`](/docs/fireskills/skills/act-3-deliver) | Ato III: Entregar | Visualiza o progresso atual de todas as especificações, estados e milestones. |

### Skills de Governança e Descoberta

| Skill | Categoria | Finalidade principal |
|---|---|---|
| [`fireskill-setup`](/docs/fireskills/skills/governance-and-decisions) | Governança | Reconcilia o contexto de `.fireskills/`, pergunta o seu nível de conhecimento e os assuntos sem resposta, e roda o monitor. |
| [`fireskill-update-spec`](/docs/fireskills/skills/governance-and-decisions) | Atualização do ciclo de vida | Trata mudanças em uma spec que já passou o Definition Gate, reabrindo só os atos e gates necessários. |
| [`fireskill-interviewer`](/docs/fireskills/skills/governance-and-decisions) | Descoberta | Permite explorar conversando as especificações em qualquer estado ativo. |
| [`fireskill-data-discovery`](/docs/fireskills/skills/governance-and-decisions) | Dados e schema | Investiga o que o produto precisa guardar em linguagem cotidiana e sincroniza o `DATABASE.md`. |
| [`fireskill-lessons`](/docs/fireskills/skills/governance-and-decisions) | Memória e aprendizado | Registra regras preventivas a partir de falhas reais em `.fireskills/lessons.json` e `LESSONS.md`. |
| [`fireskill-the-jury`](/docs/fireskills/skills/governance-and-decisions) | Tomada de decisão | Deliberação colegiada de um painel de 3 a 5 subagentes para decisões de alto impacto. |
| [`fireskill-the-fool`](/docs/fireskills/skills/governance-and-decisions) | Revisão adversarial | Submete as especificações a testes de estresse para expor premissas frágeis, casos-limite e modos de falha. |
| [`fireskill-the-judge`](/docs/fireskills/skills/governance-and-decisions) | Code review | Code review baseado em evidências que analisa PRs e diffs contra os contratos do repositório. |

### Skills de Milestones e Auxiliares

| Skill | Categoria | Finalidade principal |
|---|---|---|
| [`fireskill-mvp-milestone-interviewer`](/docs/fireskills/skills/governance-and-decisions) | Milestones | Define as milestones do Produto Mínimo Viável por meio de estados demonstráveis e testáveis. |
| [`fireskill-roadmap-milestone-interviewer`](/docs/fireskills/skills/governance-and-decisions) | Milestones | Estrutura a evolução de features pós-MVP e as milestones do roadmap. |
| [`fireskill-milestone-governor`](/docs/fireskills/skills/governance-and-decisions) | Milestones | Sincroniza as specs com as milestones e regenera a visão de roadmap `specs.md`. |
| [`fireskill-aux-stack`](/docs/fireskills/skills/governance-and-decisions) | Contexto auxiliar | Inspeciona os manifests do código para manter o `.fireskills/STACK.md` com evidência em arquivo. |
| [`fireskill-aux-rules`](/docs/fireskills/skills/governance-and-decisions) | Contexto auxiliar | Sincroniza invariantes de negócio e técnicas confirmadas em `.fireskills/RULES.md`. |
| [`fireskill-aux-database`](/docs/fireskills/skills/governance-and-decisions) | Contexto auxiliar | Sincroniza mudanças do schema Drizzle em formato de tabela no `.fireskills/DATABASE.md`. |
