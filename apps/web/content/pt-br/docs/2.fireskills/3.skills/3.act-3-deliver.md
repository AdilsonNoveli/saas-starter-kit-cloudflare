O Ato III transforma o plano em código verificado e termina no **Delivery Gate**.

| Skill | Cria ou altera | Página da etapa |
|---|---|---|
| `fireskill-07-implement` | código de produção, testes, checklists e evidência na spec, `.fireskills/*` | [Etapa 7](/docs/fireskills/getting-started/step-implement) |
| `fireskill-documentator` | `docs/` (raiz do repositório) e `.fireskills/PACKAGES.md` | [Etapa 8](/docs/fireskills/getting-started/step-documentator) |
| `fireskill-progress` | nada (projeta o estado) | [Outros pontos de entrada](/docs/fireskills/getting-started/other-entry-points) |

## `fireskill-07-implement`

Executa uma tarefa por vez (o `next_task.mjs` a escolhe), carregando o especialista da área antes de tocar em código, e marca cada item do checklist à medida que a evidência aparece. Move a spec para `in-progress` no início e para `review` quando o Delivery Gate passa; o `$fireskill-04-validate` então a aceita em `completed`. Verificação de conclusão:

```bash
bun run test                       # repository root
cd apps/app
bun run typecheck
bunx vue-tsc --noEmit -p server/tsconfig.json
```

mais o monitor de contexto e o `build_documentation.mjs --check`. O `bun run typecheck` é um script de `apps/app`; a raiz não tem nenhum.

## `fireskill-documentator`

Reconstrói `docs/` e `.fireskills/PACKAGES.md` a partir do código com o `build_documentation.mjs` (o `--check` prova que está atualizado). Roda depois de toda tarefa `[CODE]`. Não escreve a documentação pública deste site (`apps/web/content/docs/`).

## `fireskill-progress`

Projeta o estado; não altera nenhum gate nem checkbox.

```bash
bun run fireskill progress
```

Saída real em um projeto com uma spec:

```text
Summary	1 specs	0/6 tasks	0/55 items	0%
0001-convite-de-membros-por-e-mail	Draft	0/6 tasks	0/55 items	0%
```

`--json` e `--watch` estão disponíveis. A skill também oferece o `progress.mjs` e o `analyze_context.mjs` (custo de contexto de uma spec, sempre rotulado `estimated`, a não ser que o uso medido seja informado).
