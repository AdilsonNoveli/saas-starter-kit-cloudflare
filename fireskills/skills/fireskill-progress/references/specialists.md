# Specialists in Progress Projection

Use tags, files, and text of the next task to propose at most the directly
related specialists. Specialists are located in `specialists/` in this repository
(catalog in `specialists/catalog.json`).

The proposal does not alter percentage, gates, blockers, or the next task. If the
specialist is available, announce the automatic transition and load it in the same
conversation. If absent, request explicit authorization before installing or
copying.
