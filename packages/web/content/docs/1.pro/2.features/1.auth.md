## NuxFire Auth

NuxFire Pro ships with **NuxFire Auth**, an independent authentication server built on [OpenAuth.js](https://github.com/OpenAuth-js). It can secure any frontend or backend and is deployed to `auth.YOUR-DOMAIN.com`.

### Infrastructure

- **Cloudflare Worker:**
  - Configured in `infra/auth.ts` with an Assets binding for the frontend.
  - Handles auth logic in `packages/functions/src/auth.ts` using OpenAuth.js.
- **Nuxt Frontend:**

Located in the `packages/auth-frontend` package, it includes UI for:

  - Login
  - Signup
  - Forgot Password

### Key Features

- **Social Logins:** Google and GitHub authentication.
- Code-based login
- Email/password login
- Password recovery
- Email verification
- **Extendable:** Easily add new authentication methods.

## Team Authentication

Team authentication is managed within the app package: `packages/app`. It includes:

- **Team Creation** – Users can create teams and manage members.
![nuxfire Create Team Page Screenshot](/images/create-team.jpg)
- **Team Switcher** – Users can switch between multiple teams.
![nuxfire Team Switcher Page Screenshot](/images/team-list.jpg)
- **Invites & User Management** – Invite users, manage roles, and remove members.
![nuxfire User Invite Page Screenshot](/images/user-invite.jpg)
