NuxFire Pro comes with a minimal blog system built with [Nuxt Content](https://content.nuxt.com/). Just add markdown files to start publishing.

## What's Included

![Nuxflare Blogs Screenshot](/images/blog.jpg)

- Minimal blog index and post pages
- Site-wide search integration
- SEO optimization
- Responsive design
- Dark mode support
