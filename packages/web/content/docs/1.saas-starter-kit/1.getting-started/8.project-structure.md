NuxFire is a Bun workspace monorepo (`packages/*`), all under the `@nuxfire/*` namespace:

- **`packages/app`** — the main application: dashboard, team management, billing, the MFA-gated `/admin` platform console.
- **`packages/web`** — the public site: landing page, blog, and this documentation, built with Nuxt Content.
- **`packages/auth-frontend`** — the login/signup/forgot-password UI, built statically and served as the auth Worker's static assets.
- **`packages/functions`** — Cloudflare Workers code that isn't the main app: the OpenAuth auth issuer, the email Worker, the WebSockets Worker, the job/dead-letter queue consumers, and the hourly Cron Worker. Also home to `database/` — the Drizzle schema, migrations, and seed scripts.
- **`packages/emails`** — email templates, built with React Email.

Everything outside `packages/*` that isn't application code is infrastructure: `infra/*.ts` defines every Cloudflare resource as SST — see [SST.dev](/docs/saas-starter-kit/concepts/sst) for how those files load and what a stage is.
