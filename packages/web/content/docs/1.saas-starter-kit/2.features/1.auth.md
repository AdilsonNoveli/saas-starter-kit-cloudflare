## NuxFire Auth

NuxFire ships with **NuxFire Auth**, an independent authentication server built on [OpenAuth.js](https://github.com/openauthjs/openauth). It can secure any frontend or backend and is deployed to `auth.YOUR-DOMAIN.com`.

### Infrastructure

- **Cloudflare Worker:**
  - Configured in `infra/auth.ts` with an Assets binding serving the frontend's static build.
  - Handles auth logic in `packages/functions/src/auth.ts` using OpenAuth.js.
  - Credentials for password-based accounts live only in a dedicated `AuthKV` Cloudflare KV namespace, bound exclusively to this Worker — never in the Postgres database.
- **Nuxt Frontend:**

  Located in the `packages/auth-frontend` package (built statically with `nuxt generate`, served as the auth Worker's static assets), it includes UI for:

  - Login
  - Signup
  - Forgot Password

### Key Features

- **Social Logins:** Google and GitHub, each independently toggled by the `githubAuth`/`googleAuth` flags in `config.ts` — the login UI only shows a provider button once both the flag is on and its client id/secret are actually loaded as secrets.
- Code-based login
- Email/password login
- Password recovery
- Email verification
- **Extendable:** Easily add new authentication methods as needed.

## Team Authentication

Team authentication is managed within the app package: `packages/app`. It includes:

- **Team Creation** – Users can create teams and manage members.
- **Team Switcher** – Users can switch between multiple teams.
- **Invites & User Management** – Invite users, manage roles, and remove members. Server-side authorization for these actions is covered in [Role-Based Access Control](/docs/saas-starter-kit/features/rbac).
