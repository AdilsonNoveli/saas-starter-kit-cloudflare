## Runtime & language

| | Purpose |
|---|---|
| [Bun](https://bun.sh) | Package manager and JS runtime for every package and script |
| TypeScript | Every package, strict mode |

## Frontend

| | Purpose |
|---|---|
| [Nuxt 4](https://nuxt.com) | App framework — `packages/app`, `packages/web`, `packages/auth-frontend` |
| Vue 3 | Component layer under Nuxt |
| [Nuxt UI](https://ui.nuxt.com) v4 | Component library (built on Reka UI + Tailwind) |
| Tailwind CSS | Styling, plus the `forms`, `typography`, `aspect-ratio`, `container-queries` plugins |
| Pinia (`@pinia/nuxt`) | Client state — notifications store, teams store |
| VueUse (`@vueuse/nuxt`) | Composable utilities |
| `@nuxt/image` | Image optimization |
| `@nuxt/fonts` | Web font loading |
| `@nuxt/scripts` | Third-party script loading |
| `nuxt-svgo` | SVG-to-component icons |
| `@nuxtjs/i18n` | Internationalization |
| `@nuxtjs/seo` | SEO/meta tags, sitemap, OG images (`packages/web` only) |

## API layer

| | Purpose |
|---|---|
| [tRPC](https://trpc.io) (`@trpc/server`, `@trpc/client`, `trpc-nuxt`) | Type-safe API between `packages/app`'s client and server |
| [Zod](https://zod.dev) | Input validation for every tRPC procedure |

## Database

| | Purpose |
|---|---|
| PostgreSQL | Primary database — any standard instance (Supabase, RDS, Neon, self-hosted) |
| [Drizzle ORM](https://orm.drizzle.team) + Drizzle Kit | Schema, queries, migrations |
| `postgres` (postgres.js) | The actual wire-protocol driver, via Hyperdrive |

## Auth & authorization

| | Purpose |
|---|---|
| [OpenAuth.js](https://github.com/openauthjs/openauth) | The independent auth server (`packages/functions/src/auth.ts`) — password, code, GitHub, Google providers |
| [nuxt-authorization](https://www.npmjs.com/package/nuxt-authorization) | Team-scoped RBAC (Bouncer-style abilities) |
| `otpauth` | TOTP generation/verification for platform-admin MFA |
| `uqr` | Client-side QR code rendering for MFA enrollment (zero runtime deps) |

## Infrastructure — Cloudflare, via SST

Deployed entirely as code with [SST](https://sst.dev) (`sst` 4.14.0) and its Pulumi providers (`cloudflare` 6.20.0, `command` 1.0.1, `random` 4.17.0) — see [SST.dev](/docs/saas-starter-kit/concepts/sst).

| Cloudflare service | Used for |
|---|---|
| Workers | Every deployed app (App, Auth, Web, Emails, Websockets, job/DLQ consumers, Cron) |
| Hyperdrive | Postgres connection pooling from Workers |
| KV | Auth credentials (`AuthKV`), rate-limit counters, small cached values |
| R2 (via `@nuxt-hub/core`) | Blob storage — profile pictures, team logos |
| Queues | Async job processing, plus a dead-letter queue |
| Durable Objects | The WebSockets server |
| Cron Triggers | Scheduled tasks |
| Custom Domains | Every Worker's public domain, DNS handled automatically |
